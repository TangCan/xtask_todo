## Findings

### Aggregate view：契约验证覆盖不足

1. 补全测试只断言生成文本包含 `todo` 且不含 `error:`，没有调用 bash/zsh/fish 的语法检查，
   也没有验证每个静态命令/选项与 `argh` 定义同步（`xtask/src/completions.rs` 的单元测试）。
   这无法证明“脚本加载到目标 shell 后可用”。处置：defer，见 action item。

2. Agent 文档声称“增量字段保持兼容”，但 schema 文件设置 `additionalProperties: false`
   （`docs/agent-export.md` 与 `docs/todo-export-schema-v1.json`）。消费者若严格按该 schema
   校验，新增字段会被拒绝；文档与机器 schema 的扩展策略不一致。处置：defer，见 action item。
